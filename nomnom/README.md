# NOMNOM manifest

`HangballMkII.json` is the manifest for listing this mod on [NOMNOM](https://github.com/KopterBuzz/NOMNOM). After publishing the `v0.5.3` release, copy the SHA-256 shown next to `HangballMkII.dll` on the release page into `hash`, then add the file to `modManifests/` in a fork of NOMNOM and open a pull request to `main`.
