# Changelog

## 0.5.2
- Antennas unfold when the chute opens instead of at launch.

## 0.5.1
- Single-file mod: the Blueprinter bundle is embedded in `HangballMkII.dll`.

## 0.5.0
- Missile settles hanging nose-down under the chute instead of hanging level.
- Chute lines attach at the rear of the pack.

## 0.4.1 (bundle)
- Stock side fairings flattened so the stowed antennas clear them.

## 0.4.0 (bundle)
- New model: octagonal chute-pack casing with HANG markings, recessed antenna channels, folding HF wire antennas with hinge brackets, sensor nose with distributed apertures.
- Sits on the double pylon without clipping.
- Cost set to 0.126.
- New description (Hang-Aloft Node Guided).

## 0.3.0
- First release: Eyeball Mk.II clone that flies over the selected target and parachutes to loiter and spot.
